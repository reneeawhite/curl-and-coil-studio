# Research source captures

Full page captures (PDF "print to page" and one MHTML full-page save) used as primary
evidence while filling out `data/providers.csv` and `data/products.csv`, for listings that
blocked automated fetching. These are the receipts behind specific rows - see each CSV's
`notes` / `usage_notes` field for which fact came from which capture.

- `providers/hairitisbeauty_styleseat.pdf` + `hairitisbeauty_styleseat_full.mhtml` - StyleSeat
  profile for Hairitisbeauty (Kelesia Clarke), Hamden. The PDF only captured the first screen;
  the MHTML captured the full page (services, hours, policies) - prefer the MHTML.
- `providers/joyce_house_of_beauty_facebook.pdf` - Joyce House of Beauty's own Facebook page
  (address, phone, email, follower count, review status).
- `products/as_i_am_curl_clarity_shampoo.pdf` - As I Am's official product page for Curl
  Clarity Shampoo (asiamnaturally.com), which blocked automated fetch all session.
- `products/carols_daughter_goddess_strength_oil.pdf` - Carol's Daughter's official product
  page for the Goddess Strength 7 Oil Blend (carolsdaughter.com), same reason.
